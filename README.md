## How I build

- Test the data, not only the code: contracts, uniqueness and relationship checks on every model.
- Make reruns safe: idempotent loads and backfills.
- Treat cost as a metric: baseline, change one thing, measure.
- Keep business logic portable and the warehouse replaceable.
